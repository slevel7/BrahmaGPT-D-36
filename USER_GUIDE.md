# User guide

1. Choose **Enter demonstration** with a fictional role. Employee handles personal work; manager assigns project tasks; approver reviews submitted drafts; admin inspects integrations/audit; auditor is read-only. The `other` employee belongs to another isolated department.
2. In **Chat**, start a conversation and select permitted source files. Configure an actual model on the server first. No credentials means an honest configuration message. Responses are AI drafts. Review every source and administrative statement.
3. In **Documents**, upload a supported file. Click its row for extracted preview, sharing, tags and downloads. The original is preserved. **New revision** creates another version with an author, timestamp and change summary. Compare any two versions as extracted text.
4. **Generate draft** produces real DOCX/PDF/XLSX/PPTX/TXT/CSV files from your supplied facts. Choose an office note, letter, memorandum, circular, notice, report, minutes or RTI draft. No legal provision, order number or administrative fact is invented.
5. Select a reviewing officer and **Submit for approval**. Sign out, choose the demo approver, and open **Work** / **Brahma assistant** to review. Decisions are human actions on a particular version. You cannot change a document while its approval is pending.
6. In **Projects**, create a project, add an existing department account, and create tasks. Project managers can assign tasks to project members. Edit titles, priority and status; set due dates/reminders. The worker must run for reminders.
7. In project details, create an internal calendar entry with an optional manual HTTPS meeting link. Manual transcripts require participant consent. No Google/Zoom meeting is created.
8. **Brahma assistant** shows actual task/approval counts and a progress chart. Pending-task and daily-summary commands are deterministic database operations, not purported AI prose.
9. **Outreach Agent** creates synthetic campaigns and records local simulation events. Export a report. No citizen is called or messaged; no sentiment result is invented.
10. In **Customize**, pin shortcuts and change language, theme or notifications. English, Assamese and Hindi navigation is translated; many secondary administrative labels remain English. This does not imply Assamese speech support.
11. The notification bell shows your own activity. The profile page edits your details, lists sessions, and allows session revocation. Authorised admin/auditor users can view their department audit log.

Retention holds prevent destructive conversation deletion. Archive chats through their options menu. Full legal retention policy administration is not yet implemented. Help displays current integration capability status.
